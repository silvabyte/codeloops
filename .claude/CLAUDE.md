# CodeLoops contributor instructions

Follow [AGENTS.md](../AGENTS.md) for repository rules, beads tracking, and code
standards. Read [development](../docs/DEVELOPMENT.md) for the Rust/TypeScript code
map and checks. Read [contracts](../docs/OVERVIEW.md) before changing capture.

Keep daily client configuration and archives out of test runs. Preserve source
payloads and explicit coverage. Write concise docs with no em dashes. Commit,
push, or create a PR only when requested.
